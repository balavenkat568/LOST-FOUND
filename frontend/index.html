How It Works

Recovering campus belongings in 3 simple steps

📌

1. Post a Listing

Report an item you lost or found with title, category, campus location, and description.

💬

2. Private Chat

Communicate directly with the finder or owner via item-specific real-time messaging.

✅

3. Verify & Return

Verify item details (e.g. scratches, stickers), arrange handover, and mark as returned.
